# DOMAIN_OVERVIEW — void system

## O que é

Float spa de sensory deprivation em São Paulo. Clientes agendam sessões em tanques de flutuação (e massagens), compram produtos físicos e gift cards via web, e acumulam XP num sistema de gamificação chamado Void Level.

## Quem usa

**Clientes** — agendam sessões, visualizam histórico, compram na loja, usam créditos e gift cards.

**Admins** — gerenciam agenda, tanques, clientes, finanças, vendas, CRM e conteúdo do clube.

## Produtos e serviços

- **Float** — sessão de flutuação em tanque de sensory deprivation (60min, 90min, casal)
- **Massagem** — serviços de massagem
- **Combo** — float + massagem
- **Gift cards** — créditos de sessão presenteáveis
- **Produtos físicos** — loja com itens relacionados ao universo void

## Void Club

Programa de fidelidade/comunidade. Membros `void_club` e `vip` têm benefícios exclusivos. Gerenciado pelo admin via painel.

## Void Level (gamificação)

Clientes acumulam XP a cada sessão e compra. Progresso: `iniciado → explorador → habilidoso → especialista → mestre → voidwalker → transcendente`.

## Fluxos principais

1. **Agendamento** — cliente escolhe serviço, data e tanque → pagamento → confirmação → sessão
2. **Checkout** — compra de produtos, gift cards ou pacotes → pagamento → créditos aplicados
3. **Gift card** — comprador configura → checkout → destinatário resgata como crédito de sessão
4. **Admin — operação diária** — visualizar agenda, confirmar sessões, gerenciar tanques
5. **Admin — CRM** — comunicar com clientes, segmentar por lifecycle stage, enviar mensagens
